Liaisons et calculs — aide terrain

Description d'un point : Pcode String.Contrôle, ex. 526 1.1

Codes de contrôle (string Leica CS20)

.1Début de ligne
.2Fermer la forme (retour au premier point)
.3Début de courbe (arc par 3 points)
.4Fin de courbe
.5Point dans la courbe
.6Cercle par 2 ou 3 points : .6 sur le 1er point, les suivants du même string sans contrôle
.7Continuer la ligne (même effet qu'aucun code)
_Liaison multiple sur un même point. 526 1.2_2.1 : ferme le string 1 et débute le string 2. 181 1_186 1.1 : continue le 181 et débute le 186

Commandes de calcul

À inscrire dans la description de chacun des points concernés, dans l'ordre du levé. Terminer une commande avant d'en commencer une autre. Le point créé prend le prochain numéro libre.

2PPoint milieu de 2 points. Ex. 526 1_2P sur chacun des 2 points
2PDPoint à une distance sur l'alignement 1-2. Distance sur le 1er point : 526 1_2PD_1.00 puis 526 1_2PD. Distance sur le 2e : prolonge au-delà
2DIntersection de 2 distances, une par point; négative = à gauche de 1→2
3PPPerpendiculaire du 3e point sur le segment 1-2
4PIntersection des droites 1-2 et 3-4
3CCentre du cercle par 3 points. Avec .6 sur le 1er (231 1.6_3C, puis 231 1_3C) : le cercle est aussi dessiné
RECT4e coin d'un rectangle (3 points, coin au milieu)
