# Pcodes et Liaisons — Arpent-Nord

Aide-mémoire terrain sur téléphone : recherche rapide parmi les 440 Pcodes (chiffre, abréviation ou mot), liaisons et commandes de calcul, nom du fichier de levé et table NAT, secteurs des contrats reçus par lien terrain. Fonctionne hors ligne.

**Ouvrir** : https://arpent-nord.github.io/APP-PCodes/
**Version** : 2.2.0
**Documentation** : [docs/CAHIER.md](docs/CAHIER.md)
**Liste maîtresse des codes et de la NAT** : [donnees/](donnees/) — modifier là, puis `node tools/generer.js`.

Fait partie de la boîte à outils Groupe MECATECH Arpent-Nord : https://arpent-nord.github.io/
